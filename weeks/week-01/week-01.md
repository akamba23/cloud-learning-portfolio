## Linux and Terminal Commands

pwd - Show current directory. (file-navigation.png)
cd - Change the current directory. (file-management-01.png)
mkdir - Create a new directory. (file-management-01.png)
touch - Create an empty file. (file-management-01.png)
file - Show file type. (file-management-02.png)
ls - Shows the files and folders in the current directory. (file-navigation.png)
mv - Moves a file or folder to a new location. (file-management-05.png, file-management-06.png)
cp - Copies files or directories. (file-management-03.png , file-management-04.png)
cat - View, create, and combine file contents directly from the terminal. (file-management-02.png)
history - Show previously run commands. (system-monitoring.png)
